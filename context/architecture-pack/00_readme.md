# Jubely — Architecture Pack (Conceptual)

This folder contains the **conceptual architecture diagrams** and the **rules-engine architecture review** for Jubely, derived from:
- `context/Jubely Document de Cadrage Projet.md`
- `context/Architecture de déploiement.png`
- `context/ebauche de Diagramme de classes.png`
- UI inspirations in `context/template_inspirations/`

## Files
- `01_domain_glossary.md`: domain vocabulary, bounded contexts, and core flows (MVP-first).
- `02_diagrams.md`: full diagram set (C4 L1/L2, domain, sequences, rules lifecycle, event sourcing/projections, deployment, observability).
- `03_rules_engine_architecture_review.md`: architecture decisions review for rules/points (determinism, versioning, safety, auditability, performance).
- `04_mvp_super_admin_rules_spec.md`: MVP “rules fidelity” editor/tester/formula spec for super-admin, mapped to services + data.
